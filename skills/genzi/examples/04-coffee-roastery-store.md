# Example 4: Specialty Coffee Roastery Storefront

## Activation Prompt
```text
use Naff-Dev/genzi-skill build an artisanal e-commerce storefront for a specialty coffee roastery featuring single-origin bean origin cards, flavor profile radar charts, custom grind size selectors, and a recurring monthly bean subscription plan.
```

## Short Prompt (Informal)
```text
use Naff-Dev/genzi-skill buatkan storefront toko kopi roastery lokal dengan katalog biji kopi single-origin (Gayo, Toraja, Kintamani), filter rasa asam/manis/floral, dan langganan paket ngopi bulanan.
```

## Detailed Prompt with Tasting Notes & Subscriptions
```text
use Naff-Dev/genzi-skill rancang website e-commerce roastery kopi artisanal "Tanah Sangrai":
- Katalog Produk: Kartu biji kopi dengan informasi transparansi petani (origin, varietas, proses paska panen, ketinggian tanam mdpl, tanggal sangrai / roast date).
- Visual Profil Rasa: Tasting notes pills (misal: "Jasmine, Bergamot, Peach") lengkap dengan visual meter keasaman (acidity), bodi (body), dan rasa manis (sweetness).
- Selector Varian: Pilihan ukuran kemasan (200g, 500g, 1kg) dan jenis gilingan (Biji Utuh, Giling Kasar French Press, Giling Sedang V60, Giling Halus Espresso).
- Coffee Subscription Builder: Alur kuis 3 langkah memilih frekuensi (tiap 2 minggu / bulanan), jumlah kantong, dan preferensi rasa untuk berlangganan otomatis dengan diskon 15%.
- Aesthetic: Artisanal luxury mood, warm stone & espresso palette (#1C1917, #F5F0EB, #A26B35), font Playfair Display paired with Satoshi/Inter, layout editorial asimetris dengan fotografi makro biji kopi berkualitas tinggi.
```

## Iteration & Follow-up Prompts
```text
// Iterasi 1 - Brew Guide Calculator
tambahkan section kalkulator seduh interaktif: masukkan jumlah kopi (gram) atau rasio air (1:15, 1:16), lalu hitung otomatis takaran air dan tampilkan timer stopwatch bertahap (bloom, pour 1, pour 2).

// Iterasi 2 - Roastery Story & Roaster's Notes
buatkan section 'Cerita Petani & Filosofi Sangrai' dengan transisi scroll horizontal halus, menampilkan potret petani mitra di Aceh Tengah dan profil mesin roasting Probat.

// Iterasi 3 - Direct Checkout via QRIS & Midtrans
integrasikan slide-out cart drawer dengan voucher diskon berlangganan, perhitungan estimasi ongkir instan Paxel Cold Chain, dan pilihan bayar QRIS.
```

```text
use Naff-Dev/genzi-skill build a premium specialty coffee roastery web store. Highlight origin terroir (altitude, varietal, wash process), interactive flavor note tags, roast-to-order dispatch scheduler, and custom subscription bundle box configurator.
```
